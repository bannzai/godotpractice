# 燈環闘技

夕暮れの工業都市で、二人の装甲闘士が競う1人用の2D格闘ゲーム。

リポジトリルートで `make -C games/fighter run` を実行して起動する。タイトルから闘士を選び、CPUとの試合に進む。1ラウンド99秒、2本先取。体力が0になるか時間切れでラウンドが終了する。残り体力が同じ場合は本数を加算せず再ラウンドになる。

蒼は移動と技の発生が速く、燈は威力とリーチに優れる。対戦相手は選ばなかった闘士。

## 操作

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 移動・しゃがみ・ジャンプ | WASD / 矢印 | 十字キー / 左スティック |
| 弱パンチ | J | 西のフェイスボタン |
| 強パンチ | K | 北のフェイスボタン |
| 弱キック | U | 南のフェイスボタン |
| 強キック | I | 東のフェイスボタン |
| 決定・再戦 | Enter / Space | 南のフェイスボタン / Start |
| 戻る（選択・結果画面） | Esc | 東のフェイスボタン / Back |
| 一時停止・再開 | Esc | Start |
| 音のオン・オフ | M | Guide |
| 全画面切替 | F11 | — |

メニューはマウスでも操作できる。ボタン位置で案内しているため、パッドに印刷された文字が違っても同じ配置で操作する。

- 立ち・しゃがみ・空中それぞれに4種類、合計12種類の通常技がある。
- 後ろ入力でガード。下段のしゃがみキックは斜め下後ろで防ぐ。空中攻撃は立ちガードで防ぐ。空中ではガードできない。
- 必殺技「燈波」は、下 → 斜め下前 → 前 ＋ パンチを素早く入力する。右向きでは S → S+D → D+J、左向きでは S → S+A → A+J。強パンチでも発動する。
- 技の途中と被弾硬直中は新しい技を出せない。命中・ガード・空振りで技の終了までの時間が変わる。

## 検証と素材

シーンやautoloadを変更した後は `make -C games/fighter run` で、エディタなしのウィンドウにタイトルが表示されることを確認する。自動確認には `FIGHTER_VERIFY_RUN=1 make -C games/fighter run` を使える。同じ通常起動経路で描画を `games/fighter/tmp/run-title.png` に保存し、正常終了する。環境変数を指定しない通常起動とreleaseビルドでは自動終了しない。

`make test GAMES=fighter` は技性能・実Area2D接触・コマンド入力・試合状態と、キーボード／パッドの入力による画面遷移を検証する。

`make screenshot GAMES=fighter` はタイトル・選択・対戦・全12通常技の途中・命中・ガード・必殺技・KO・勝敗結果・タイトル復帰・全画面を撮影する。`make movie GAMES=fighter` は起動から5秒の映像を生成する。

素材の出典・生成条件とフォントの利用条件は `assets/CREDITS.md` に記録している。音声は `python3 games/fighter/scripts/dev/generate_audio.py` で同じ内容に再生成できる。
