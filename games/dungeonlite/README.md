# 灯守の迷宮

剣と回避で迷宮を進む2Dローグライト。六つの部屋を越えて最深部の主を倒すか、途中で欠片を持ち帰り、焚き火で恒久強化を購入する。

## 起動

Godot 4.7の通常版で `project.godot` を開くか、このディレクトリで実行する。

```sh
make run
```

## 操作

| 入力 | 動作 |
| --- | --- |
| WASD / 矢印 | 移動・剣の向き |
| マウス移動 | マウスの方向に剣を向ける |
| J / 左クリック長押し | 連続攻撃 |
| Space | 移動方向に無敵回避。静止中は剣の方向 |
| E | 制圧後、右の扉の近くで次へ |
| 1 / 2 / 3 | 部屋制圧後の強化を選ぶ |
| Esc | 一時停止・再開 |
| M | 音のオン・オフ |

敵を全滅させると体力が1回復し、扉が灯る。次の部屋へ進む場合は今回の探索だけの強化を一つ選ぶ。帰還を選べば欠片を全量持ち帰り、死亡・探索中断では半分を持ち帰る。恒久強化は自動保存される。ウィンドウを直接閉じた場合、未帰還の探索は保存されない。

## 検証

```sh
make test
make screenshot
```

`make test` はheadlessでロジックを検証する。`make screenshot` は実ウィンドウを短時間開いて操作を検証し、リポジトリルートの `tmp/dungeonlite/` にPNGを出力する。描画検証にはGUIが必要。通常セーブは変更しない。

素材の作者・ライセンスは `assets/CREDITS.md` を参照。
