# 宵の陣

札を伏せ、王を守りながら五つの夜を越える、一人用の盤面戦略ローグライク。

## 起動

Godot 4.7 のエディタで `project.godot` を開くか、リポジトリのルートで次を実行する。

```sh
make boardrogue-run
```

## 遊び方

手札を選び、自陣の空きマスをクリックして配置する。盤上の伏せ札を選んで「登場させる」を押し、「攻めに進む」から自札と攻撃対象を順に選ぶ。攻撃可能な敵が朱色に光る。敵王の命を10削れば勝利。

攻撃力の小さい札は捨て場へ移り、攻撃側が勝つと前進する。同値なら相討ち。射撃札は勝っても前進しない。移動した札はその手番に攻撃できない。準備中は隣接する味方一組を配置換えできる。

通常の道では通常札、将軍の道では希少札を一枚得る。王の残体力と軍勢は次の夜に引き継ぎ、勝利時に命を2回復する。最終夜の敵王を倒せば制覇。敗北すると遠征は終わる。

遠征は街道に戻るたび自動保存する。戦闘中に終了した場合は道の選択時点から再開する。新しい遠征を始めると以前の保存を置き換える。

| キー | 操作 |
| --- | --- |
| 数字 | 手札選択 |
| 矢印・Enter | 盤上のマスを選ぶ・決定 |
| R / X | 登場 / 配置換え |
| Space / K | 次の段階 / 敵王への攻撃 |
| H / M / Esc | 手ほどき / 音 / メニュー |

## 検証

`games/boardrogue/` で `make import` の後に `make test`。描画付きの操作検証と撮影は `make screenshot`、マウス・キーボード両経路の検証は `make inputcheck`。画像出力はリポジトリの `tmp/boardrogue-captures/` に置く。デスクトップウィンドウを開ける環境が必要。

デスクトップ向けの書き出しは `make build-linux`・`make build-windows`・`make build-macos`。対応するGodotのエクスポートテンプレートが必要。生成先はゲーム内の `build/`。署名・ストア公開は行わない。

画像のうち五列の満員盤面と勝敗の代表画面は、表示確認専用に構成する。ゲーム進行の成立は別途、合法手による対戦・遠征テストで確認する。
