# 素材の出典

## 独自の画像・音声

背景、人物肖像、札の表裏の SVG は、このゲームのために Codex が SVG のパスと図形を記述したオリジナル作品です。夜の山と灯籠に囲まれた軍議卓、架空の兵士・軍師・龍を題材にしています。第三者の画像、作品名、ロゴ、キャラクターは使用していません。画像生成サービスは使用していません。

WAV 音声は Python 標準ライブラリで正弦波、倍音、指数減衰、乱数ノイズを合成したオリジナル音源です。24 秒の音楽は撥弦を思わせる五音音階の旋律、効果音は札の配置・攻撃・勝利・敗北を表しています。第三者の録音や既存楽曲を使用していません。

これらの独自素材には、第三者から要求されるクレジット表記・ライセンス同梱義務はありません。
