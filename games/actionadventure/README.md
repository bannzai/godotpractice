# 残り火の森

剣を携えた旅人が、森の祠から灯火を受け取り、眠れる灯台を目覚めさせる見下ろしアクションアドベンチャー。岸・森・祠・封印の庭・灯台を歩いて巡る、短い一つの冒険です。画像と BGM・効果音はこのゲーム用のオリジナルです。

## 起動

リポジトリのルートで実行します。Godot 4.7 の GL Compatibility を使用します。

```sh
make -C games/actionadventure run
```

Godot の場所が異なる場合は `GODOT=/path/to/godot` を指定できます。

## 操作

| キー | 操作 |
| --- | --- |
| WASD / 矢印 | 移動、石を押す |
| J / Z | 向いている方向へ剣を振る。押し続けて連続攻撃 |
| Space / K | 回避。右上のゲージが戻ると再使用可能 |
| E / X | 近くを調べる。灯火を取得すると炎を放つ |
| Tab / Esc | 地図と一時停止 |
| M | 消音の切り替え |
| Enter | 開始、敗北後の再開、クリア後の新しい冒険 |

森の魔物を倒すと宝箱から鍵を取得できます。森の北にある祠で鍵を使い、石を金色の床へ押して祭壇を調べると灯火が手に入ります。東の庭にある二本の燭台を灯し、北の灯台の守護者を倒して祭壇を調べるとクリアです。

敵の輪と線は攻撃の予告です。敵を倒すと体力が少し回復し、岸の休息地点では全回復します。押し石を動かし損ねた場合は、祠の左側の床を調べて戻せます。敗北しても取得物・解いた仕掛け・討伐結果を保持して現在の部屋から再開します。進行はアプリ実行中のみ保持します。

## 検証

```sh
make -C games/actionadventure test
make -C games/actionadventure screenshot
```

`test` は Godot の読み込み、戦闘・進行・出口の境界条件、移動と通常攻撃による通しクリアを検証します。通しクリア検証では進行フラグ・敵の体力・プレイヤー位置を直接変更しません。

`screenshot` はウィンドウを開き、Godot へキー入力を送って開始・移動・回避・剣・地図・仕掛け・再開を確認し、リポジトリの `tmp/actionadventure-*.png` に代表画面を保存します。進行後半の描画では部屋と取得物のフィクスチャを使うため、この検証単独を通しプレイとはみなしません。

macOS の Godot 4.7 で検証しています。Windows・Linux の実行と配布用エクスポートは未検証です。日本語表示にはシステムフォントを使用します。
