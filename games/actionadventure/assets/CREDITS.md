# 素材の出典

`atlas.png` と `ambient.wav`・`swing.wav`・`hit.wav`・`chime.wav` は、このゲーム用に Codex が記述した `scripts/dev/generate_assets.gd` を Godot で実行して制作したオリジナル素材です。外部の画像・録音・楽曲・商標は使用していません。入手 URL はありません。

制作方針は、苔緑・クリーム・朱色・深紺の 16 ピクセルの見下ろし絵、白い髪と赤茶の外套の旅人、草木と石造遺跡、穏やかな旋律と短い操作音です。画像生成サービスは使用せず、画素定義と波形合成で生成しています。第三者素材に基づくライセンス条件・クレジット義務はありません。権利の扱いは本リポジトリの方針に従います。
