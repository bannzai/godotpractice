# 素材の出典

- 結晶アイコン `crystal.svg`: このゲームのために作成したオリジナルの SVG。六角形の結晶と三角形の面をコードで構成。第三者素材は使用していない。
- 盤面・結晶・粒子: Godot の描画 API によるオリジナルの図形。
- BGM・効果音: `scripts/main.gd` で正弦波から PCM を合成するオリジナル音源。外部の楽曲や録音は使用していない。
- 文字: 実行環境にインストールされた日本語対応システムフォントを利用。フォントファイルの同梱・再配布は行わない。

生成 AI による画像・音声生成サービス、原作の名称・ロゴ・素材は使用していない。
