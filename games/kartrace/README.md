# 潮風カート

海と灯台を囲むサンゴ湾サーキットを、CPU3台と3周走る3Dアーケードレースです。しずく・あかね・すみれは車体の形と、加速・最高速・ハンドリングが異なります。

リポジトリルートで `make kartrace-run` を実行すると起動します。

## 操作

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 車種選択 | ← / →、マウス | 左スティック |
| 開始・再走 | Enter、マウス | A |
| アクセル | ↑ / W | RT |
| ブレーキ・バック | ↓ / S | LT |
| ハンドル | ← / →、A / D | 左スティック |
| ドリフト | Space とハンドル | X と左スティック |
| アイテム | E | B |
| タイトルへ | Esc | 戻るボタン |
| 全画面切替 | F11 | — |
| 消音切替 | M | — |

ドリフト中に同じ方向を保ち、火花が出てから解除すると短く加速します。黄色い箱からは、前方へ飛ばすパルス、後ろに置くブイ、自分を加速するターボのいずれかが手に入ります。

コースのミント色の板はダッシュ板、内側の木の橋はショートカットです。壁に当たると減速し、柵のない場所で落ちると直前のチェックポイントへ戻ります。バック中は周回が増えません。ゴールした時点でベストタイムを保存し、全車が到着すると実測タイムの順位表を表示します。

## 検証

共通のコマンドと成功条件はルートの AGENTS.md に従います。`make test GAMES=kartrace` は純粋ロジックの selfcheck に加え、キーボードとパッドの入力イベントを使う integration を実行します。

ゲームディレクトリの `make movie-play` は25秒の実入力プレイ、2秒間隔の一覧画像、末尾フレームを `tmp/` に作ります。通常終了の検証はルートで `make kartrace-run RUN_ARGS='--script res://scripts/dev/run_smoke.gd'` を実行します。

通常起動での裸の `--quit-after` は音声の終了処理を持ちます。Movie Maker はフレーム単位で音声を同期処理するため、専用 `movie.gd` / `demo.gd` の事前停止経路を使います。任意のフレーム数を直接指定して録画する場合は、`--quit-after N -- --audio-stop-at-frame N` を渡します。

素材の出典・生成方法は assets/CREDITS.md、設計判断と検証知見は documents/knowledge/kartrace.md に記録しています。
